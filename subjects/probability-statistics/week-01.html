TOPIC 02

Discrete & Continuous Random Variables

Discrete Random Variable (DRV)

A random variable is called a discrete random variable if its set of possible outcomes/values is countable.

A discrete random variable takes distinct, separate values.

Continuous Random Variable (CRV)

A continuous random variable can take any value over a continuous interval.

Unlike a discrete random variable, its possible values are not limited to separate countable points.

Classification Examples from the Notes

Random Variable Type
Number of automobile accidents occurring per year in Hyderabad Discrete
Length of time to play 18 holes of golf Continuous
Amount of milk produced by a cow Continuous
Useful interpretation: Counts generally produce discrete values, whereas measured quantities such as time and amount generally produce continuous values.

TOPIC 03

Probability Mass Function (PMF) & Probability Distribution

Definition

Suppose X is a discrete random variable having at most a countable number of values

x₁, x₂, x₃, ...

With each possible value xᵢ, associate the probability

P(X = xᵢ) = p(xᵢ)

The function p is called the Probability Mass Function of the discrete random variable X.

The set of pairs {(xᵢ, p(xᵢ))} gives the probability distribution of X.

Conditions of a PMF

1) p(xᵢ) ≥ 0    for every i
2) Σ p(xᵢ) = 1
A probability table is a valid PMF only when both conditions are satisfied.

Checking PMF — Example 1

xᵢ-2-1012
p(xᵢ)0.10.20.30.10.3

First condition:

p(xᵢ) ≥ 0

All probabilities are non-negative.

Second condition:

0.1 + 0.2 + 0.3 + 0.1 + 0.3 = 1
Therefore both conditions are satisfied and the given distribution is a valid PMF.

Checking PMF — Example 2

xᵢ-101
p(xᵢ)0.400.6
0.4 + 0 + 0.6 = 1
Both PMF conditions are satisfied. Therefore it is a valid PMF.

Checking PMF — Example 3

xᵢ0123
p(xᵢ)0.10.20.10.3
0.1 + 0.2 + 0.1 + 0.3 = 0.7 ≠ 1
The second PMF condition is not satisfied. Therefore the given distribution is not a valid PMF.

TOPIC 04

Probability Density Function (PDF)

Definition

Let X be a continuous random variable. If the probability over an interval is given by

P(a ≤ X ≤ b) = ∫ₐᵇ f(x) dx

then the real-valued function f(x) is called a Probability Density Function (PDF), provided the following conditions are satisfied.

Conditions of PDF

1) f(x) ≥ 0
2) ∫₋∞^∞ f(x) dx = 1

Probability at a Single Point

For a continuous random variable,

P(X=a) = P(a ≤ X ≤ a)
P(X=a) = ∫ₐᵃ f(x) dx = 0
Therefore the probability of a continuous random variable taking one exact value is zero.

Numerical — Piecewise PDF

The class notes give:

f(x) = 0,    x < 0

f(x) = kx,    0 ≤ x < 1

f(x) = k(x+1),    1 ≤ x < 2

f(x) = 0,    x ≥ 2

(i) Find the value of k

Given:
The above piecewise function is a PDF.
Formula:
Using the second condition of PDF,
∫₋∞^∞ f(x)dx = 1
Substitution:
∫₋∞⁰ 0 dx + ∫₀¹ kx dx + ∫₁² k(x+1) dx + ∫₂^∞ 0 dx = 1
Therefore,
k∫₀¹ x dx + k∫₁²(x+1)dx = 1
Calculation:
k[x²/2]₀¹ + k[x²/2 + x]₁² = 1
k(1/2) + k(5/2) = 1
3k = 1
Final Answer: k = 1/3

(ii) Find P(0 < X ≤ 1.5)

Given:
k = 1/3
Formula:
P(0 < X ≤ 1.5) = ∫₀¹⋅⁵ f(x)dx
Substitution: Because the PDF changes at x=1,
P(0 < X ≤ 1.5) = ∫₀¹ (x/3)dx + ∫₁¹⋅⁵ ((x+1)/3)dx
Calculation:
= (1/3)[x²/2]₀¹ + (1/3)[x²/2+x]₁¹⋅⁵
= 1/6 + 3/8
= 4/24 + 9/24
= 13/24
Final Answer: P(0 < X ≤ 1.5) = 13/24

TOPIC 05

Cumulative Distribution Function (CDF)

Definition

Let X be a random variable. The Cumulative Distribution Function is defined by
F(x) = P(X ≤ x)

For a Discrete Random Variable

F(x) = Σ p(t),   t ≤ x

For a Continuous Random Variable

F(x) = ∫₋∞ˣ f(t)dt

Properties of CDF

Property 1

F(-∞) = 0
F(+∞) = 1

Property 2

0 ≤ F(x) ≤ 1

Property 3 — Non-decreasing Property

If x < y, then

F(x) ≤ F(y)

Interval Probability Relations

The notes record the following CDF relation:

P(a < X ≤ b) = F(b) - F(a)

For a continuous random variable, because the probability at a single point is zero:

P(X=a)=0
therefore the endpoint differences do not affect interval probability in the same way as for a discrete variable. The notes consequently obtain:
P(a ≤ X ≤ b) = F(b) - F(a)
and
P(a < X < b) = F(b) - F(a)
for the continuous case shown in the class work.

Relation Between PDF and CDF

For a continuous random variable:

F(x) = ∫₋∞ˣ f(t)dt

Thus the CDF accumulates the probability density from -∞ up to x.
