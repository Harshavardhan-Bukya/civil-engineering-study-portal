Bivariate Random Variable (BRV)

Definition: Let S be a sample space associated with a random experiment. If the random experiment is represented by the pair (X,Y), then it is called a Bivariate Random Variable (BRV).

If X and Y are discrete random variables, then (X,Y) is called a discrete bivariate random variable.

If X and Y are continuous random variables, then (X,Y) is called a continuous bivariate random variable.

Joint Probability Mass Function (JPMF)

Let (X,Y) be a discrete BRV. Its joint probability mass function is denoted by:

PXY(xi,yj) = P(X=xi,Y=yj)

for a value (xi,yj) of (X,Y). It is zero otherwise.

Conditions for JPMF

PXY(xi,yj) ≥ 0   for all (xi,yj)
Σi Σj PXY(xi,yj) = 1
Remember: Every probability must be non-negative and the total probability of all possible pairs must be 1.

Marginal PMF of X

Conditional Probability Mass Function

Let (X,Y) be a discrete bivariate random variable. The conditional probability of X given Y=y is:

PX|Y(xi|yj) = PXY(xi,yj) / PY(yj) ,   PY(yj) ≠ 0

Similarly, the conditional probability of Y given X=x is:

PY|X(yj|xi) = PXY(xi,yj) / PX(xi) ,   PX(xi) ≠ 0
05

Worked Discrete BRV Problem

Consider the joint PMF of the bivariate random variable (X,Y):

PXY(x,y) = k(x + 2y),   x = 0,1,2   and   y = 0,1

and

PXY(x,y) = 0   otherwise

Questions

  1. Find the value of k.
  2. Find the marginal PMF.
  3. Find the conditional PMF.
  4. Find P(X ≤ 1).
  5. Determine whether X and Y are independent.

Step 1 — Find k

Since the total probability must be 1:
Σx=02 Σy=01 k(x+2y) = 1
Therefore,
k[(0+0)+(0+2)+(1+0)+(1+2)+(2+0)+(2+2)] = 1
k(12) = 1
k = 1/12

Joint PMF

PXY(x,y) = (x+2y)/12

Step 2 — Marginal PMF of X

PX(x) = Σy=01 (x+2y)/12
PX(x) = (x+1)/6
x PX(x)
0 1/6
1 2/6
2 3/6

Marginal PMF of Y

PY(y) = Σx=02 (x+2y)/12
PY(y) = (1+2y)/4
y PY(y)
0 1/4
1 3/4

Step 3 — Conditional PMF

PX|Y(x|y) = PXY(x,y)/PY(y)
PX|Y(x|y) = (x+2y)/[3(1+2y)]

Similarly:

PY|X(y|x) = (x+2y)/[2(x+1)]

Step 4 — Find P(X ≤ 1)

P(X ≤ 1) = P(X=0)+P(X=1)
= 1/6 + 2/6 = 1/2
Answer: P(X ≤ 1) = 1/2
06

Independent Random Variables

Definition: Two random variables X and Y are said to be independent if:
PXY(x,y) = PX(x) PY(y)

Independence Test for the Worked Problem

For the given joint PMF:

PXY(x,y) = (x+2y)/12

Compare this with:

PX(x)PY(y) = [(x+1)/6][(1+2y)/4]
These two expressions are not equal in general.
Conclusion: X and Y are dependent random variables.

Joint Probability Density Function

Let (X,Y) be continuous random variables. The joint probability density function is denoted by fXY(x,y).

For a region a ≤ x ≤ b and c ≤ y ≤ d:

Conditional Probability Density Function

The conditional PDF of X given Y=y is:

fX|Y(x|y) = fXY(x,y) / fY(y) ,   fY(y) ≠ 0

Similarly, the conditional PDF of Y given X=x is:

fY|X(y|x) = fXY(x,y) / fX(x) ,   fX(x) ≠ 0
Important: Conditional density is obtained by dividing the joint density by the corresponding marginal density.
